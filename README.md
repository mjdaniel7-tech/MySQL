# Solar System Explorer
## Overview
The Solar System Explorer is a MySQL and Python portfolio project that demonstrates relational database design, SQL programming, and a Streamlit web interface.
The application allows users to explore planets, moons, space missions, mission photos, and mission videos through an interactive interface.
---
## Features
- Planet database
- Moon database
- NASA/JPL mission information
- Mission photos
- Mission videos
- Search by planet
- Interactive Streamlit interface
- Relational MySQL database
---

---
## Installation
Install Python packages:
```bash
pip install -r requirements.txt
```
Run the application:
```bash
streamlit run app.py
```
